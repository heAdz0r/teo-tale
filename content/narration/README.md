# Режиссура озвучки

`direction.json` — единственный редактируемый источник произношений и
интонационной разметки. Исходный текст глав при этом не меняется.

## Произношения

В `pronunciations` перечислены словоформы. Поле `say` использует синтаксис
Silero: знак `+` ставится непосредственно перед ударной гласной. Например,
`Т+эо` читается как «ТЭ́О». Для склоняемого имени нужно добавить каждую форму,
которая реально встречается в книге. Обычные слова и омографы не следует
исправлять глобально: для них безопаснее cue с точным контекстом и полем `say`.

## Интонационные cues

`anchor` — точная уникальная цитата из главы. Доступные параметры:

- `say`: произносимый вариант цитаты, если одного словаря недостаточно;
- `rate`: `x-slow`, `slow`, `medium`, `fast`, `x-fast`;
- `pitch`: `x-low`, `low`, `medium`, `high`, `x-high`;
- `beforeMs`, `afterMs`: пауза в миллисекундах;
- `note`: редакторское объяснение, не попадающее в аудио.

Разметка проверяется до загрузки модели:

```bash
npm run tts:validate
```

Проверка завершится ошибкой, если anchor исчез после редактуры, встретился
несколько раз, пересёк границу сегмента либо содержит недопустимый параметр.
После любой правки `direction.json` меняется ревизия аудио; старый CDN-кэш не
может подменить новую режиссуру.
