# Продолжения сказки

Семь глав продолжают пятую аудиосказку. Основной текст каждой рассчитан
примерно на 11–12 минут спокойного чтения вслух. Редакторские заметки перед
разделителем читать ребёнку не нужно.

| Глава | Название | Что усиливает |
|---|---|---|
| VI | `06-porog-bez-prikazov.md` | Талос — принц; причина одиночного пути; родители; последствия хитрости Тео |
| VII | `07-otvet-svistka.md` | Первое применение свистка и клинка; Лея; правило Сумеречного леса |
| VIII | `08-zerkalo-pervogo-snega.md` | Кража из сокровищницы; опасность одного сезонного фрагмента; сомнение в Талосе |
| IX | `09-golos-v-beloy-perchatke.md` | Отражённый голос Талоса; граница подсказок Весемира; первый замок весенней двери |
| X | `10-voron-kotoryy-znal.md` | Сон-предупреждение; причина слежки Талоса-ворона; Орт и зеркальная дорога |
| XI | `11-sovet-kotoryy-skazal-net.md` | Публичное признание Талоса; правило дара убеждения; возвращение прежних свидетелей |
| XII | `12-golos-bez-prikaza.md` | Второе применение свистка; изобретение отца; завершение дворцовой линии Орта |

Рабочая последовательность: VI → VII → VIII → IX → X → XI → XII. Главы IX–XII
реализуют маршрут «Принц, которому все верят»: Талос не побеждает более сильным
приказом, а раскрывает правду, позволяет совету отказать ему и добровольно
ограничивает дар. Большая линия продолжается дорогой к Тихому Часу и весенней
хранительнице; люди в белых перчатках, вероятно, уже владеют зимней, летней и
осенней частями.
