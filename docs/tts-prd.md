# PRD: выразительная озвучка «Летописи Тео»

Дата: 12 августа 2026 года. Статус: Silero MVP реализован и проверен.

## Проблема и цель

Все XVIII глав доступны в читалке, но только первые пять имеют исходные авторские записи. Нужно дать ребёнку и взрослому непрерывное прослушивание истории на русском языке: с корректной кириллицей, естественными ударениями, паузами и эмоционально уместной, но не театрально избыточной интонацией.

Цель MVP: локально сгенерировать озвучку Silero `v5_5_ru` в web-ready OGG, а кнопкой «Озвучить» в читалке запускать текущую главу целиком. Читатель выбирает один из пяти русских голосов. Произношение и подача управляются версионируемой режиссёрской разметкой, не изменяющей печатный текст. На Cloudflare публикуются только статические файлы — без Python, GPU, API-ключей и оплаты за прослушивание. Пока конкретная глава не сгенерирована, используется системный русский голос браузера.

| [Yandex SpeechKit](https://yandex.cloud/ru-kz/docs/speechkit/tts/request) | русский — основной язык; эмоции, ударения, паузы и фонемы | REST/gRPC, OGG/MP3/WAV | облачный сервис, IAM/API key | сильный кандидат для A/B после MVP |
| [Chatterbox Multilingual V3](https://huggingface.co/ResembleAI/chatterbox) | русский из коробки, voice cloning, контроль подачи | Python/PyTorch, отдельный GPU-сервис | MIT | лучший self-hosted кандидат для пакетной генерации |

| [Silero TTS v5.5_ru](https://github.com/snakers4/silero-models) | русские ударения, омографы, вопросы, SSML; легче LLM-TTS | локально на CPU/GPU | upstream обозначает лицензию весов как CC-NC-BY; нельзя использовать коммерчески без отдельного разрешения | выбран для семейного MVP |
| [Piper](https://github.com/OHF-voice/piper1-gpl) | есть `ru_RU`, быстрый CPU/ONNX, но менее выразителен | CLI/Python/C++ | GPL-3.0, лицензии голосов проверяются отдельно | accessibility/offline, не основной рассказчик |
| [XTTS-v2](https://huggingface.co/coqui/XTTS-v2) | русский и клонирование голоса | Python/GPU | CPML разрешает только non-commercial use | не выбирать для будущего коммерческого сценария |

Качество — не только свойство модели: русский референс-голос, редактура ударений имён и контроль стыков между сегментами требуют отдельного прослушивания. Заявления поставщиков не заменяют аудио-eval на текстах Тео.

## Пользовательский сценарий MVP

1. Читатель открывает любую готовую главу, выбирает рассказчика и нажимает «Озвучить».
2. Интерфейс показывает подготовку, затем воспроизводит сегменты без ручного переключения.
3. Кнопка переключается в паузу/продолжение; отдельная кнопка останавливает и сбрасывает главу.
4. Интерфейс прямо сообщает, что звучит Silero. Если статический OGG ещё не сгенерирован, используется `speechSynthesis` с `ru-RU`.
5. При переходе на другую главу запросы и воспроизведение прежней главы прекращаются.

## Архитектура и безопасность

- `content/chapters.ts` — единый источник текста для страницы; Python-генератор читает те же Markdown-файлы напрямую.
- `content/narration/direction.json` — канонический словарь ручных ударений и точных режиссёрских cues. JSON Schema и runtime-валидация не допускают неизвестных голосов, SSML-значений и устаревших текстовых якорей.
- `scripts/generate_silero_narration.py` загружает закреплённую модель `v5_5_ru`, переводит разметку в поддерживаемый Silero SSML, синтезирует на CPU и кодирует Opus через `ffmpeg`.
- Сегменты не длиннее 700 символов и режутся по предложениям: так Silero сохраняет локальный интонационный контекст и не получает нестабильно длинный вход.
- Структура абзацев и сцен сохраняется: SSML добавляет отдельные межабзацные и межсценовые паузы; cue может задать `rate`, `pitch`, `beforeMs`, `afterMs` и произносимый вариант конкретной фразы.
- SHA-256-ревизия полного текста и всей режиссуры входит в имя каждого OGG. После изменения главы, словаря или cue UI получает новый URL из манифеста и не воспроизводит устаревшую запись из CDN.
- Результат лежит в `public/audio/narration/<voice>/chapter-N/<revision>-<part>.ogg`; Cloudflare обслуживает его как immutable static asset.
- Модель кэшируется в игнорируемой `.cache/silero/`; на production она не отправляется. API endpoint и секреты отсутствуют.
- Лицензионное ограничение Silero фиксируется рядом с аудио и в `manifest.json`. Этот вариант подходит семейному некоммерческому проекту; коммерческая публикация требует отдельного решения.

## Критерии приёмки MVP

- Все главы I–XVIII серверно рендерят контрол озвучки.
- Селектор предлагает все пять голосов `v5_5_ru`, а каждый пункт имеет полный пакет глав.
- Имя Тео синтезируется как `Т+эо`; склоняемые имена имеют явные словоформы с ручным ударением.
- Некорректный или устаревший cue останавливает генерацию до загрузки модели.
- Длинная глава автоматически воспроизводится несколькими ограниченными сегментами.
- Пауза, продолжение, остановка и переход между сегментами работают с клавиатурой и экранным диктором.
- При отсутствии сгенерированного файла нет необработанной ошибки: включается русский системный голос или показывается понятное состояние отсутствия голоса.
- Повторный запуск генератора идемпотентен: совпадающие ревизии не синтезируются заново без `--force`.
- Короткий sample и выбранная глава успешно генерируются на Apple Silicon CPU и воспроизводятся браузером.
- Production build, lint и серверные tests проходят.

## После MVP

1. Провести редакторское прослушивание пяти полных пакетов и уточнить cues по конкретным таймкодам; автоматические правила — только исходная режиссёрская версия, не замена слухового контроля.
2. По результатам прослушивания расширить словарь редкими словоформами и контекстными омографами; отдельно нормализовать появившиеся цифры словами.
3. Пакетно сгенерировать утверждённые главы; при росте размера перенести те же revision-addressed assets в R2.
4. Добавить таймкоды абзацев, подсветку читаемого текста и сохранение позиции.
5. Перед клонированием семейного голоса получить явное согласие владельца записи и зафиксировать допустимые способы использования.
